# PIXEL TEXAS · 像素德州扑克

小丑牌（Balatro）画风的无限注德州扑克。支持局域网联机房间对战、机器人补位、三档机器人水平，全部像素渲染 + 程序合成音效，无需任何美术素材。

![玩法](https://img.shields.io/badge/模式-单机%20%2F%20联机-ff9f43) ![引擎](https://img.shields.io/badge/规则-无限注德州现金桌-66bb6a)

## 快速开始

```bash
npm install
npm start
```

浏览器打开 **http://localhost:3000** 即玩。控制台会同时打印局域网地址（如 `http://192.168.31.42:3000`），同一 WiFi 下的朋友用浏览器打开该地址即可联机。

## 功能

- **个人中心**：主菜单点头像进入 —— 12 种像素图案 × 8 色自选头像、改昵称、生涯统计（局数/胜率/净盈亏/VPIP/PFR/激进度/摊牌胜率/最佳牌型/风格标签），数据跨房间累计并落盘保存（`data/profiles.json`）
- **对局辅助**：牌桌上实时显示自己的蒙卡胜率（随公共牌与人数即时更新）、行动倒计时环、其他玩家本街已行动的绿勾标识、All-in 全屏闪光
- **四色牌面**：♠ 深藏蓝 / ♥ 红 / ♦ 亮蓝 / ♣ 绿，梅花黑桃一眼可辨
- **四种主题**：经典绿桌 / 霓虹夜 / 赌场红绒 / 暗夜石墨 —— 背景纹理、桌面呢绒、强调色、按钮基调整体切换（菜单右上角选择）
- **单机练习**：一键开局，机器人自动补位
- **快速匹配**：自动加入有人且有空位的公开房间，没有就自动建房
- **快速锦标赛**：一键开局锦标赛（机器人陪打）
- **创建房间**：生成 4 位房间码，朋友「输入房间码加入」；大厅同时展示房间列表（锦标赛房有标记）
- **两种模式**：
  - **现金桌**：随时补买、可「休息一手」/「回到牌局」、连续 3 次超时自动休息
  - **锦标赛**：人人等码起步，盲注按手数升级（间隔可调 4/6/8/12 手），打光即淘汰，决出完整排名，冠军可「重新开赛」
- **机器人**：房间内勾选「机器人自动补位」，三档水平
  - **休闲**：松而被动，爱跟注，偶尔迷之操作
  - **普通**：蒙特卡洛胜率 + 底池赔率 + 位置意识，偶尔诈唬
  - **大师**：更高模拟次数，下注尺度随胜率与牌面纹理变化，会半诈唬、反加注、短码推弃
- **房间设置**（房主）：人数上限 2–9、盲注级别、初始买入、机器人水平、模式、升盲间隔、行动时限（15/30/60 秒）
- **规则完整**：标准盲注（含单挑规则）、最低加注与全下不足额加注重开判定、**边池/平分池**、行动超时托管（可看则看，否则弃牌）
- **牌局回放与战绩**：最近 30 手流水可逐步回放（发牌 → 每个行动 → 公共牌 → 摊牌，支持自动播放/进度条）；房间内每人局数/胜场/净盈亏统计
- **赢家成牌高亮**：摊牌时构成最佳牌型的 5 张牌金框高亮
- **背景音乐**：程序合成 8-bit 循环曲目三首（霓虹夜晚 / 绿桌风云 / 暗流涌动）+ 自动模式，音量与曲目在菜单可调，局内一键开关，切后台自动暂停
- **动画与氛围**：漂浮花色粒子背景、桌面 logo 呼吸、发牌/筹码飞行动画、屏幕震动、赢家高亮、WebAudio 合成音效、CRT 扫描线滤镜、像素完美缩放

## 操作

| 场景 | 操作 |
| --- | --- |
| 行动 | 弃牌 / 看牌 / 跟注；加注用滑条或快捷键（2.5BB、½池、满池、全下） |
| 休息 | 现金桌点「休息一手」暂停打几手，「回到牌局」恢复 |
| 破产 | 现金桌点「补充筹码」重新买入；锦标赛打光即淘汰 |
| 个人中心 | 主菜单点头像：改昵称/头像、查看生涯统计 |
| 回放/战绩 | 牌桌右上角「回放」「战绩」按钮 |
| 音乐/主题 | 菜单右上角调音量/曲目/主题；局内「音乐:开/关」一键切换 |
| 房间码 | 房间等待界面点「[复制]」复制给朋友 |

## 项目结构

```
server/                 服务端（Node.js，唯一依赖 ws）
  index.js              HTTP 静态服务 + WebSocket 入口（端口 3000，可用 PORT 环境变量改）
  lobby.js              房间注册、快速匹配、房间码、会话重连、个人档案与风格分析
  room.js               座位、机器人补位、行动计时、锦标赛盲注阶梯、手牌流水归档、快照广播
  hand.js               牌局状态机：盲注→下注轮→公共牌→边池结算（含 VPIP/PFR 采集）
  evaluator.js          7 选 5 牌型评估（加密安全洗牌）+ 成牌 5 张提取
  bots/bot.js           三档机器人 AI（蒙特卡洛胜率复用 evaluator）
  storage.js            JSON 落盘（个人档案 data/profiles.json）
client/                 前端（原生 ES Module，无构建步骤）
  js/render.js          主菜单 / 房间等待 / 牌桌 / 回放·战绩·个人中心面板（960×540）
  js/cards.js           四色像素卡牌、花色点阵图、筹码堆
  js/avatar.js          像素头像（12 图案 × 8 色）
  js/theme.js           主题系统（经典绿桌/霓虹夜/赌场红绒/暗夜石墨）
  js/equity.js          浏览器端蒙卡胜率（与服务端同一套打分）
  js/ui.js              即时模式 UI：按钮 / 复选框 / 循环选择 / 滑条
  js/fx.js              粒子、漂浮文字、屏幕震动、All-in 闪光、音效合成
  js/music.js           8-bit 背景音乐步进音序器（三首循环曲目，后台自动暂停）
  js/net.js             WebSocket 封装（断线重连、?guest 多开模式）
  assets/fonts/         缝合像素字体（Fusion Pixel，OFL 许可）
test/                   测试（npm test）
  evaluator.test.js     评估器：6 万手随机与暴力对拍 + 已知牌断言
  hand.test.js          状态机：1500 手随机整局筹码守恒 + 边池构造用例
  server.test.js        全链路：登录→练习→机器人→匹配→顶替→重连→锦标赛→回放→档案→休息
```

## 架构说明

- **服务器权威**：洗牌、评估、结算全在服务端；私有底牌只发给对应连接，摊牌才广播明牌。客户端只做表现层，每条事件后跟随全量快照，断线重连即恢复。
- **机器人即玩家**：机器人是服务端座位对象，与真人共用同一条牌局流程；真人加入满员房间时顶替最后入座的机器人（手牌进行中则排队到本手结束）。
- **像素画面**：整帧绘制在 960×540 画布上，CSS 整体放大 + `image-rendering: pixelated`，中文使用缝合像素字体，卡牌与花色为程序化点阵绘制。

## 同机多开测试

普通打开的多个标签页共享同一会话（刷新即重连）。若想在同一台电脑模拟多个玩家，给第二个标签页加 `?guest` 参数：

```
http://localhost:3000/?guest
```

每个 `?guest` 标签页拥有独立身份，互不影响。
